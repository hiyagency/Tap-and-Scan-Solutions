# NFC keychain import

Four products added as unpriced catalogue defaults. Existing Supabase product edits take precedence. Owner catalogue Save persists a new entry; the additive seed script can also insert missing entries without overwriting existing ones.

Do not run the seed against production until the corresponding code and photos are deployed. No production database writes or deployments were performed for this import.
